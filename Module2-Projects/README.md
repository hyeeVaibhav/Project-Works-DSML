# Statistics Practice - Sales Data

**Author:** Vaibhav Singh

## Overview

This Jupyter Notebook contains simple statistics practice using a small sales dataset created directly in Python.

## Topics Covered

- Hypothesis Testing
- One-Sample t-Test
- Normal Distribution Fitting
- Kolmogorov-Smirnov Goodness-of-Fit Test
- A/B Test Simulation
- Two-Proportion z-Test
- Correlation Matrix
- Correlation Heatmap
