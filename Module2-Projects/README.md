


Statistics Practice - Sales Data
Author: Vaibhav Singh

Overview
This Jupyter Notebook contains simple statistics practice using a small sales dataset created directly in Python.

Topics Covered
Hypothesis Testing

One-Sample t-Test

Normal Distribution Fitting

Kolmogorov-Smirnov Goodness-of-Fit Test

A/B Test Simulation

Two-Proportion z-Test

Correlation Matrix

Correlation Heatmap

Requirements
Install the required Python libraries:

pip install numpy pandas matplotlib seaborn scipy
How to Run
Open Statistics_Practice_Sales_Data_Clean.ipynb in Jupyter Notebook, JupyterLab, Google Colab, or VS Code and run the cells from top to bottom.

Dataset
No external CSV or Excel file is required. The sales data is created directly inside the notebook using NumPy.
