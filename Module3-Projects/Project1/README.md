# 📈 Linear Regression — Student Marks Prediction

A beginner-friendly Machine Learning project that uses **Simple Linear Regression** to predict student marks based on the number of hours they study.

This project focuses on understanding the complete workflow of a Linear Regression model using Python and Scikit-learn.

---

## 🎯 Objective

The main objective is to answer:

> **Can we predict a student's marks based on their study hours?**

The model learns the relationship between:

```text
Study Hours → Marks
