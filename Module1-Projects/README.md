# 📺 Netflix Content Exploration

A mini **Exploratory Data Analysis (EDA)** project using Python to analyze Netflix movies and TV shows.

### 🛠️ Tools

* Python
* Pandas
* Matplotlib
* Seaborn
* Jupyter Notebook

### 📊 Analysis

* Movies vs TV Shows
* Content ratings
* Release year trends
* Top countries
* Missing-value handling
* Data visualization

### 📁 Files

* `Netflix_Content_Exploration_Mini_Project.ipynb` — Analysis notebook
* `netflix_titles_sample.csv` — Sample dataset
